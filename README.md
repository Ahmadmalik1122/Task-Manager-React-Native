📝 Smart Task Manager Pro
🚀 Overview

Smart Task Manager Pro is a high-performance, cross-platform mobile application built with React Native (Expo) and Firebase Cloud Firestore. The purpose of this app is to help users efficiently organize their daily tasks while making task creation smarter and faster with AI-powered features.

✨ Key Features
AI-Integrated Voice-to-Task: Python-based AI integration that understands voice commands, automatically converts them into text, and saves tasks directly into Firebase.
Firebase Authentication: Secure login and signup system.
Real-time Cloud Firestore: Instant data storage and synchronization.
Activity Hub: Productivity analytics dashboard where users can view the percentage of total, pending, and completed tasks.
Smart Soft-Delete: Uses a ‘hidden’ logic flag instead of permanently deleting tasks for better data safety.
Dynamic Task Scheduling: Built-in date and time picker for setting task schedules.
Professional UI/UX: Clean dark-themed interface that provides a premium user experience.
🛠️ Technical Stack
Mobile Frontend: React Native (Expo SDK)
Programming Language: TypeScript
Backend: Google Firebase (Authentication & Firestore)
AI Logic: Python (Voice Parsing & Processing)
Build & Deployment: EAS (Expo Application Services)
Navigation: Expo Router
