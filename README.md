# 📝 Smart Task Manager Pro

### 🚀 Overview

Smart Task Manager Pro is a high-performance, cross-platform mobile application built on **React Native (Expo)** and **Firebase Cloud Firestore**. The app's goal is to help users efficiently organize their daily tasks while making task creation smarter and faster with AI-powered features.

---

### ✨ Key Features

* **AI-Integrated Voice-to-Task:** Python-based AI integration that understands voice commands, automatically converts them to text, and saves tasks directly to Firebase.
* **Firebase Authentication:** Secure login and signup system for all users.
* **Real-time Cloud Firestore:** Instant data storage and synchronization across all devices.
* **Activity Hub:** Productivity analytics dashboard where you can view your total, pending, and completed tasks as percentages.
* **Smart Soft-Delete:** Uses a 'hidden' logic flag instead of permanently deleting tasks to ensure data safety.
* **Dynamic Task Scheduling:** Built-in date and time picker for flexible task scheduling.
* **Professional UI/UX:** Clean, dark-themed interface that delivers a premium user experience.

---

### 🛠️ Technical Stack

* **Mobile Frontend:** React Native (Expo SDK)
* **Programming Language:** TypeScript
* **Backend:** Google Firebase (Authentication & Firestore)
* **AI Logic:** Python (Voice parsing & processing)
* **Build & Deployment:** EAS (Expo Application Services)
* **Navigation:** Expo Router
