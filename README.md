📝 Smart Task Manager Pro
🚀 Overview
Smart Task Manager Pro is a high-performance, cross-platform mobile application built using React Native (Expo) and Firebase Cloud Firestore. The primary goal of this application is to help users organize their daily tasks efficiently, while integrating smart, AI-powered features to make task creation faster and more intuitive.

✨ Key Features
AI-Integrated Voice-to-Task: Python-based AI integration that interprets voice commands, converts them into text automatically, and saves them directly to the Firebase database.

Firebase Authentication: A secure and reliable login and signup system for personal user accounts.

Real-time Cloud Firestore: Instant data storage and seamless synchronization across devices.

Activity Hub: An intelligent productivity analytics dashboard that calculates and displays the percentage of total, pending, and completed tasks.

Smart Soft-Delete: Ensures data safety by utilizing a 'hidden' logic flag instead of permanent deletion, maintaining data integrity.

Dynamic Task Scheduling: Integrated built-in date and time picker for precise task deadline management.

Professional UI/UX: A clean, dark-themed interface designed to provide a premium and modern user experience.

🛠️ Technical Stack
Mobile Frontend: React Native (Expo SDK)

Programming Language: TypeScript

Backend: Google Firebase (Authentication & Firestore)

AI Logic: Python (Voice parsing & processing)

Build & Deployment: EAS (Expo Application Services)

Navigation: Expo Router
