  # 📝 Smart Task Manager App

### 🚀 Overview

Smart Task Manager Pro is a high-performance, cross-platform mobile application developed using React Native and Firebase. The primary goal of this application is to help users organize their daily tasks efficiently while ensuring real-time data synchronization across multiple devices via the cloud.

### ✨ Key Features
* **Firebase Authentication: A secure login and signup system for personal user accounts.**
* **Real-time Cloud Firestore: Instant data storage and synchronization using Google's NoSQL database.**
* **Smart Soft-Delete: Advanced task management with isDeleted logic for data safety and integrity.**
* **Dynamic Task Scheduling: Integrated DateTime Picker for precise task deadline management.**
* **Professional UI/UX: A clean, dark-themed interface with Glassmorphism for a premium experience.**
* **Optimized Queries: Implemented Firebase Indexing for fast data retrieval and filtering.**
### 🛠️ Technical Stack
* **Frontend: React Native (Expo Framework)**
* **Programming Language: TypeScript*
* **Backend/Database: Google Firebase (Auth \& Firestore)**
* **Build \& Deployment: EAS (Expo Application Services)**
* **Navigation: Expo Router for seamless file-based transitions.**
